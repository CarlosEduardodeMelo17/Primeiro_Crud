# 📋 Primeiro CRUD

Este repositório contém um **protótipo de um sistema CRUD (Create, Read, Update e Delete)** desenvolvido como parte dos meus estudos em desenvolvimento back-end. O projeto teve como objetivo compreender a estrutura básica de operações de cadastro, consulta, atualização e remoção de dados.

## 🚀 Objetivo

Desenvolver um CRUD simples para praticar conceitos fundamentais de programação e organização de aplicações, servindo como base para projetos mais completos no futuro.

## ✨ Funcionalidades

* ➕ Cadastro de registros
* 📄 Listagem de registros
* ✏️ Atualização de informações
* ❌ Exclusão de registros
* 🔍 Consulta de dados

> Por se tratar de um protótipo, algumas funcionalidades podem estar em desenvolvimento ou serem simplificadas para fins de aprendizado.

## 🛠️ Tecnologias utilizadas

* Java
* Banco de dados (conforme implementação do projeto)
* Git
* GitHub
* SpringBoot

## 📂 Estrutura do projeto

```text
Primeiro_Crud/
```

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Cmelodev/Primeiro_Crud.git
```

2. Entre na pasta do projeto:

```bash
cd Primeiro_Crud
```

3. Execute o arquivo principal:

```bash
python nome_do_arquivo.py
```

> Caso o projeto utilize um banco de dados, certifique-se de configurá-lo antes da execução.
